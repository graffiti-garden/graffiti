# Graffiti Examples

These example applications show how the Graffiti API, decentralized
implementation, and Vue plugin fit together in complete client-side social
apps.

| Application | What it demonstrates | Live site | Source |
| --- | --- | --- | --- |
| Glitter | A Twitter-like public short-form social feed with profiles and follows | [glitter.graffiti.garden](https://glitter.graffiti.garden/) | [`examples/glitter`](./glitter/) |
| Parallax | A messenger-like group chat where moderation is personal to each participant | [parallax.graffiti.garden](https://parallax.graffiti.garden/) | [`examples/parallax`](./parallax/) |
| Provenance | A messenger-like group chat that interoperates with Parallax but with a different moderation system | [provenance.graffiti.garden](https://provenance.graffiti.garden/) | [`examples/parallax`](./parallax/) |
| Wikiffiti | A collaborative, extensible wiki | [wiki.graffiti.garden](https://wiki.graffiti.garden/) | [`examples/wikiffiti`](./wikiffiti/) |
