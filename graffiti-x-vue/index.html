This library exposes capabilities of the Graffiti server. Specifically it

  • toggleLogIn: A function that let's you log in and out of the Graffiti server.
  • myID: A unique user identifier when you're logged in.
  • useCollection: A Vue Composable that let's you retrieve and modify collections of social data from the Graffiti server --- this is where the magic happens!

Collections

We can create collections of objects with the useCollection composable. The composable takes a query as an input and exposes three things: objects: a list of objects in the queries update: a function to add or replace an object matching the query remove: a function to remove an object matching the query. Let's see how we can use these three things to create a collection of "boops". Let's try it (don't forget you need to be logged in for this to work!
