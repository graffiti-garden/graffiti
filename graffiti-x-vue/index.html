Graffiti for Vue 3

This is the frontend interface to the Graffiti server that let's you add custom, reactive social features to any static website. Specifically, the library exposes three properties:

  • toggleLogIn: A function that let's you log in and out of the Graffiti server via email.
  • myID: A unique string associated with your account.
  • useCollection: A Vue Composable that let's you retrieve and modify collections of social data from the Graffiti server — this is where the magic happens!

Collections

We can create collections of objects with the useCollection composable. The composable takes a query as an input and exposes three things: objects: a reactive array of all objects in the server that match the query. update: a function to add or replace an object matching the query to the server. remove: a function to remove an object matching the query from the server
